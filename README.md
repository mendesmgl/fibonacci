# Fibonacci | Sequência de Fibonacci

## English

A beginner-friendly C program that calculates the n-th term of the Fibonacci sequence. The function receives a position `n` and returns the corresponding element using an iterative approach.

### Technologies

C

### How to run

Compile with GCC:

```bash
gcc fibonacci.c -o fibonacci
```

Run the program:

```bash
./fibonacci
```

### Example

For `n = 7`, the program displays:

```text
O seu termo 7 equivale ao número: 13
```

### What I learned

- How to create a function that returns the n-th Fibonacci term.
- How to use iteration to calculate a sequence.
- How to handle the first terms and non-positive positions.
- How to receive and display integer input in C.

### Future improvements

- Add validation for invalid or non-numeric input.
- Use a wider integer type for larger Fibonacci positions.
- Allow the user to calculate multiple terms without restarting the program.
